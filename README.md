# مِعيار — تطبيق محادثة القدرات

تطبيق جوال عربي RTL بواجهة محادثة مركزة لتدريب اختبار القدرات في السعودية. التجربة الحالية تشبه تطبيقات المساعدات الذكية: محادثة جديدة، قائمة محادثات، رسائل، ردود تدريبية، أدوات سريعة، وإدخال نصي مناسب للجوال.

## تشغيل محلي

```bash
npm install
npm run start
```

يحتوي المشروع على إعداد npm صغير لتثبيت peer dependencies الخاصة بـ Expo Router بشكل ثابت عبر بيئات التطوير المختلفة.

ثم افتح المشروع عبر Expo Go أو شغّل نسخة الويب:

```bash
npm run web
```

## الفحوصات

```bash
npm run typecheck
npm run export:web
```

## هيكل المشروع

- `app/`: مسارات Expo Router.
- `src/components/`: واجهة المحادثة ومكوناتها.
- `src/data/chat.ts`: الردود التجريبية والأسئلة الأولية.
- `src/theme/`: ألوان ومسافات وهوية الواجهة.
- `tasks/`: خطة التنفيذ وقائمة المهام.

## أمان الذكاء الاصطناعي

النسخة الحالية تستخدم محاكيًا محليًا للتدريب حتى لا تُكشف أي مفاتيح داخل التطبيق. عند ربط نموذج ذكاء اصطناعي حقيقي يجب أن يمر الاتصال عبر API خادمي، مع مصادقة وحدود استخدام وتسجيل أخطاء، ولا يوضع مفتاح المزود في `EXPO_PUBLIC_*`.

## الحالة الحالية

هذه نسخة UI/MVP قابلة للتشغيل. الخطوة الإنتاجية التالية هي ربط الحسابات، قاعدة الأسئلة، حفظ المحادثات، وخدمة AI خادمية مع مراجعة المحتوى قبل النشر.
