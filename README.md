# ترندكس — علي بابا والمنصات

موقع عربي للدخول مباشرة على المنتجات بأسعار **ريال سعودي** من:
علي بابا، علي إكسبريس، أمازون، وعروض فنون.

## التشغيل

```bash
npm ci
npm run dev
```

## السلوك

- الصفحة الرئيسية تعرض المنتجات فورًا (بدون هيرو طويل)
- الضغط على المنتج يفتح صفحة المنتج `/product/[id]`
- زر الشراء ينقلك للمنصة مباشرة
- فلترة حسب المنصة والفئة والبحث

## بيانات حية (اختياري)

```bash
ALIEXPRESS_APP_KEY=...
ALIEXPRESS_APP_SECRET=...
ALIEXPRESS_TRACKING_ID=...
```
