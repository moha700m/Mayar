# مِعيار — تطبيق محادثة القدرات

تطبيق جوال عربي RTL بواجهة محادثة واحدة لتدريب اختبار القدرات السعودي. التجربة تشبه مساعدًا ذكيًا: شاشة فارغة هادئة، محادثة، حالة تفكير، رد تدريجي، أدوات سريعة، ودرج محادثات. ليست لوحة تحكم وليست موقعًا ويب.

## تشغيل محلي

```bash
npm ci
npm run start
```

ثم افتح المشروع عبر Expo Go، أو شغّل معاينة الويب فقط للفحص:

```bash
npm run web
```

المشروع يستخدم `legacy-peer-deps=true` لتثبيت اعتمادات Expo Router بشكل ثابت عبر بيئات التطوير المختلفة.

## الفحوصات

```bash
npm run typecheck
npx expo config --json
```

## هيكل المشروع

- `app/`: مسارات Expo Router. الشاشة الوحيدة هي المحادثة.
- `src/components/`: واجهة المحادثة ومكوناتها.
- `src/data/chat.ts`: محاكي الردود التدريبية المحلية، والأسئلة والاقتراحات.
- `src/theme/`: الألوان، المسافات، الخطوط، وقواعد الحركة.
- `src/hooks/`: تقليل الحركة، الاتصال، ولوحة المفاتيح.
- `DESIGN.md`: نظام التصميم وقرارات الواجهة.
- `tasks/`: خطة التنفيذ وقائمة المهام.

## التصميم

الهوية داكنة هادئة: Ink `#0D0F12`، ذهب `#D7B674`، نعناع `#8AD6B5`. التفاصيل البصرية والحركة موثّقة في `DESIGN.md`. الواجهة RTL حقيقية عبر `direction: 'rtl'` ومحاذاة عربية، وليست قلبًا أفقيًا فقط.

لا توجد مكتبات UI جديدة. الحركة تعتمد على React Native `Animated` و`LayoutAnimation` المضمّنتين، حتى تبقى خفيفة على iOS وAndroid.

## أمان الذكاء الاصطناعي

النسخة الحالية تستخدم محاكيًا محليًا داخل `src/data/chat.ts` حتى لا تُكشف أي مفاتيح داخل التطبيق. عند ربط نموذج حقيقي يجب أن يمر الاتصال عبر API خادمي، مع مصادقة وحدود استخدام، ولا يوضع مفتاح المزود في `EXPO_PUBLIC_*`.

## الحالة الحالية

واجهة محادثة جاهزة للتدريب البصري والوظيفي. الخطوة التالية إنتاجيًا: حسابات، حفظ المحادثات، قاعدة أسئلة، وخدمة AI خادمية مع مراجعة المحتوى قبل النشر.
